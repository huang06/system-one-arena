System-1 LLM Arena

Pick a game and pit 2–4 system-one (non-reasoning, fast) models against each other on the same seed. Each step makes one LLM call and uses the first character of the reply as the action.

Bots come from config.json. Edit endpoints under “Endpoint settings” on any game page; all games share them. Every bot joins by default; untick “Join” on a game page to leave one out.
